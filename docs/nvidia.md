# MX330: офлайн-набір NVIDIA 580.196.07 для Feodal 0.6

Це **необов’язковий** набір для GeForce MX330/Pascal на свіжому
Feodal **0.6.0-1**, x86_64, з ядром **7.2.14-arch1-1**. В ISO драйвера NVIDIA
немає: робочий стіл починає працювати на Intel. `nvidia-open` для MX330 не підходить.

Набір містить три зібрані пакети AUR (64-бітні бібліотеки, DKMS та 32-бітні
бібліотеки), п’ять офіційних EGL-залежностей Arch із підписами, ліцензію NVIDIA,
контрольні суми та походження джерел. На ноутбуці не потрібно запускати рецепти
AUR. Компіляцію модуля перевірено з цим ядром; **роботу на фізичній MX330, Vulkan,
сон/пробудження та FPS без ноутбука не перевірено**.

## Перед встановленням

- Збережи резервну копію. Secure Boot має бути вимкнено.
- Прочитай `NVIDIA-LICENSE.txt`; встановлюй драйвер лише якщо приймаєш умови.
- Виконай `feodal-gaming status` і перевір модель GPU.
- Перевір `uname -r` та `pacman -Q linux linux-headers`. Цей набір перевірено
  саме з комплектним ядром. Для іншого/оновленого ядра потрібна окрема перевірка.
- Не встановлюй цей набір поверх актуальної гілки `nvidia-utils`, `nvidia-open`
  чи іншої гілки NVIDIA. Не понижуй оновлену систему заради старих EGL-пакетів.
- Не став `nvidia-prime`: залежність може підтягнути несумісну актуальну гілку
  NVIDIA. Feodal має власний запуск PRIME без цього пакета.

## Встановлення на свіжий Feodal 0.6

Завантаж `feodal-mx330-580.196.07-x86_64.tar` із релізу Feodal. Розпакуй **у свою
домашню директорію Linux**, не на FAT/NTFS-флешку (в назві одного пакета є `:`).
Наприклад, якщо архів лежить у поточному каталозі:

```sh
tar -xf feodal-mx330-580.196.07-x86_64.tar
cd feodal-mx330-580.196.07
sha256sum -c SHA256SUMS
less NVIDIA-LICENSE.txt
sudo pacman -U ./*.pkg.tar.zst
```

Перевір план pacman перед підтвердженням: мають бути саме пакети **580xx**,
а не 615xx чи `nvidia-open`. Локальні пакети NVIDIA зібрані Feodal й не мають
підпису Arch; цілісність перевіряється через опубліковані суми. Офіційні залежності
мають окремі підписи Arch. **Не вимикай перевірку підписів**, якщо pacman відхилив
транзакцію.

Дочекайся завершення DKMS без помилок; на повільному CPU це займає кілька хвилин.
Потім:

```sh
dkms status
sudo mkinitcpio -P
sudo reboot
```

Для потрібного ядра DKMS має показати `installed`, не лише `added`. Якщо збірка
не вдалася, не обирай NVIDIA в налаштуваннях: спочатку переглянь журнал
`/var/lib/dkms/nvidia/580.196.07/` або повернись до Intel за інструкцією нижче.

## Після перезавантаження

```sh
nvidia-smi
feodal-hardware
__NV_PRIME_RENDER_OFFLOAD=1 __GLX_VENDOR_LIBRARY_NAME=nvidia __VK_LAYER_NV_optimus=NVIDIA_only vulkaninfo --summary
```

Перевір, що NVIDIA відповідає й Vulkan справді бачить MX330. Після цього відкрий
**Super+I → Ігри / GPU → NVIDIA / PRIME** та запусти Steam. Перед зміною режиму
повністю закрий Steam. Режим стосується запуску через Feodal, не всіх програм.

Dota 2 використовуй як нативну Linux-гру. Для GTA V **Legacy Story Mode** обери
Proton у властивостях гри в Steam. **GTA Online під Linux не підтримується через
BattlEye**; драйвер і оболонка цього не змінюють. Почни з 1280×720 та низьких
налаштувань, закрий зайві програми. Конкретного FPS не обіцяємо.

## Повернення до Intel

У центрі керування поверни звичайний запуск Steam. Якщо графічний сеанс не
відкрився, увійди у текстову консоль через Ctrl+Alt+F2. Видалити ці три пакети:

```sh
sudo pacman -Rns lib32-nvidia-580xx-utils nvidia-580xx-dkms nvidia-580xx-utils
sudo mkinitcpio -P
sudo reboot
```

Не видаляй Mesa, Intel Vulkan чи їхні 32-бітні бібліотеки. Звичайна команда
`steam` у терміналі не використовує збережений NVIDIA-режим панелі Feodal.

Це зафіксована версія драйвера, не сервіс автоматичних AUR-оновлень. Після змін
ядра перевіряй DKMS; драйвер і 32-бітні бібліотеки потрібно оновлювати узгоджено.
Джерела: [NVIDIA supported GPUs](https://download.nvidia.com/XFree86/Linux-x86_64/580.196.07/README/supportedchips.html),
[ArchWiki NVIDIA](https://wiki.archlinux.org/title/NVIDIA), [PRIME](https://wiki.archlinux.org/title/PRIME).
