# Ігрові налаштування Feodal 0.2

Відкрий **Налаштування** на панелі, натисни **Super + I**, або запусти
`feodal-panel --settings`. Вікно створюється лише на запит, окремого резидентного
сервісу немає. Доступні система/діагностика, вибір GPU для Steam, інструменти й
інструкція з підготовки ігор.

## Діагностика

Кнопка перевірки читає ядро, доступну RAM, PCI/DRM-пристрої та прив'язаний драйвер.
Також перевіряє наявність Steam, `prime-run` і відповідь `nvidia-smi`. Перевірка
відбувається поза GTK-потоком із тайм-аутом команди, без прав адміністратора.
NVIDIA може пробудитися під час опитування; постійного опитування немає.

```sh
feodal-hardware
```

CLI повертає JSON. Він не збирає серійні номери, MAC-адреси чи список процесів.
Успішна відповідь NVIDIA **не доводить**, що Vulkan/PRIME або конкретна гра
працюють. Наявність `prime-run` сама по собі не означає наявності драйвера.

## Вибір GPU

- **Звичайний запуск:** виконує `steam` без додаткового примусового вибору GPU.
- **NVIDIA / PRIME:** виконує `prime-run steam`, лише якщо Steam/PRIME встановлені
  й діагностика підтверджує NVIDIA. За відсутності компонентів показує пояснення,
  не переходить мовчки на інший GPU й не встановлює пакети.

Перед зміною режиму **повністю закрий уже запущений Steam**. Налаштування діє лише
на кнопку Steam на панелі та в центрі керування. Воно не переписує сторонні
`.desktop` файли, не впливає на запуск Steam зі звичайного меню програм і не
перемикає глобальний GPU сеансу. Для окремої гри можна використати параметр
`prime-run %command%` після перевірки драйвера.

Вибір зберігається у `$XDG_CONFIG_HOME/feodal/preferences.json` або
`~/.config/feodal/preferences.json`. Запис атомарний, файл доступний власнику;
невідомі/пошкоджені значення означають звичайний запуск, а не виконання довільної
команди. У непостійному live-сеансі налаштування зникнуть після перезапуску.

## MX330 та ігри

MX330 належить до Pascal. Для пропрієтарного драйвера потрібна сумісна гілка
580xx, не `nvidia-open`, заголовки обраного ядра та відповідні 32-бітні бібліотеки.
AUR-пакети не включені й не встановлюються автоматично: їх треба перевіряти й
збирати звичайним користувачем. Не змішуй `nvidia-utils` поточної гілки з legacy
580xx. Центр керування не є інсталятором драйверів і не змінює Xorg/initramfs.

Для Steam в Arch потрібні multilib і графічні бібліотеки обох потрібних
розрядностей; конкретні пакети залежать від драйвера. Перед змінами дивись
[ArchWiki NVIDIA](https://wiki.archlinux.org/title/NVIDIA),
[PRIME](https://wiki.archlinux.org/title/PRIME) та
[Steam](https://wiki.archlinux.org/title/Steam).

Dota 2 має нативну Linux-версію; для GTA V Legacy Story Mode потрібен Proton.
GTA Online має обмеження BattlEye під Linux. Власна оболонка не усуває ці
обмеження. Поки що фізична MX330 й самі ігри не перевірені, FPS не гарантований.

## Сеанс

Перед запуском панелі та Openbox сеанс передає DISPLAY/XAUTHORITY й змінні XDG
у середовище активації D-Bus/systemd-user. Це дозволяє активованим графічним
службам знаходити поточний X11-дисплей; весь процесний environment не передається.
Ця зміна не додає блокування екрана, постійного сховища чи графічного інсталятора.
