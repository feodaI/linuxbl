# Feodal Linux — prototype 0.4

Власна легка оболонка для дистрибутива на **Arch Linux зі стандартним ядром Linux**.
Це початковий робочий прототип, а не готовий до щоденного використання дистрибутив.
Попередній live ISO 0.3 перевірений у BIOS та UEFI QEMU: [результати](docs/verification-0.3.md).
У 0.4 додано [системний трей і повсякденні функції](docs/desktop.md).
Результати поточної збірки: [перевірка 0.4](docs/verification-0.4.md).
Історичні результати: [перевірка 0.2](docs/verification-0.2.md).
У версії 0.3 додано [Firefox і базові програми](docs/browser.md).
У версії 0.2 додано [центр керування й ігрові налаштування](docs/gaming.md).

## Що реалізовано

- Нативні GTK 3 панель, фон і меню програм із пошуком за назвою/описом.
- Запуск встановлених `.desktop` програм через Gio, без виконання пошукового рядка як команди.
- Список вікон поточного робочого столу, активація й згортання, годинник.
- Firefox із локальною стартовою сторінкою Feodal; Mousepad, Xarchiver, mpv у live ISO.
- Мінімалістична темна панель 40 px: значки браузера, файлів, термінала й Steam, задачі з підкресленням активної, EN/UK, годинник із датою та живлення.
- Спливне меню програм із пошуком, що закривається при кліку поза ним; узгоджені тема Openbox, xterm, трей і сповіщення.
- Діагностика Intel/NVIDIA, пам'яті й драйверів; збереження режиму запуску Steam.
- Звук і мережеві з'єднання через інструменти центру керування.
- Openbox керує вікнами; два робочі столи, без композитора, розмиття, Electron чи вебдвигуна.
- Arch-пакет і скрипт побудови live ISO: [інструкція](docs/iso.md).

Це власна панель і меню поверх готового менеджера вікон, **не власний композитор**.
Поточна версія розрахована на X11 та один основний екран. Немає
блокування екрана, графічного інсталятора, автоматичного налаштування NVIDIA та
повного набору системних налаштувань. Інструмент мережі відкриває редактор з'єднань; мережевий індикатор доступний у треї. Для захищеного щоденного використання потрібне подальше
налаштування блокування, авторизації та керування живленням.

## Встановлення оболонки на Arch

У корені цього checkout:

```sh
sudo pacman -Syu --needed base-devel
cd packaging
makepkg -si
```

`makepkg` запускається **звичайним користувачем**, не root. Вибери **Feodal** у
менеджері входу, або з локальної текстової консолі виконай:

```sh
startx /usr/bin/feodal-session
```

Команда `feodal-hardware` показує діагностичний JSON без прав адміністратора.

Скрипти не форматують диски й не змінюють завантажувач. Закриття сеансу закриває
програми: спочатку збережи документи. Встановлення пакета не підміняє інші сеанси.

## MX330 / i3-1115G4 / 8 ГБ

MX330 належить до Pascal: не встановлюй `nvidia-open` для неї. Потрібні сумісні
пакети legacy-гілки 580xx, заголовки встановленого ядра та відповідні 32-бітні
бібліотеки для ігор. AUR-пакети треба перевіряти й збирати окремо; ISO їх не містить.
Драйвер Intel/Mesa використовується для звичайної роботи; NVIDIA можна залучати
через PRIME. Це ще не перевірено на цільовому ноутбуці.

Dota 2 має нативну Linux-версію. GTA V Legacy Story Mode потребує Proton;
GTA Online має обмеження BattlEye. Steam не встановлюється автоматично і потребує
multilib. У тестовому Xvfb-сеансі пік RSS процесу оболонки під час відкриття меню був приблизно
78 МіБ після вимкнення непотрібного GL-контексту (до зміни — близько 262 МіБ
у тому самому тесті). Вимкнення діє лише на оболонку: середовище дочірніх програм
відновлюється. Це не вимір усієї ОС і не результат на цільовому ноутбуці.
Немає обіцянок конкретного FPS чи споживання RAM усією системою.
Для live ISO додано zram зі стисненням zstd: половина обсягу RAM, максимум
4 ГіБ логічного swap. Пам'ять виділяється за потреби; zram не додає фізичної RAM
і не гарантує підвищення FPS. Також додано PipeWire/PulseAudio-сумісний сервер
і WirePlumber. Фізичні звук, Wi-Fi та GPU потребують перевірки на ноутбуці.

## Перевірка оболонки без Arch ISO

На Ubuntu/Debian для локальних UI-тестів:

```sh
sudo apt-get install python3-gi python3-cairo python3-gi-cairo gir1.2-gtk-3.0 \
  gir1.2-wnck-3.0 openbox xvfb xauth xdotool xterm dbus-x11
./tests/run.sh
```

Тести запускають справжні GTK-вікна та Openbox у віртуальному X-сервері, перевіряють
пошук, відкриття/закриття меню, запуск термінала, список вікон, активацію й межі
максимізованого вікна. Це **не перевірка завантаження ISO, драйвера чи ігор**.

Джерела: [Archiso](https://wiki.archlinux.org/title/Archiso),
[NVIDIA](https://wiki.archlinux.org/title/NVIDIA),
[PRIME](https://wiki.archlinux.org/title/PRIME).
